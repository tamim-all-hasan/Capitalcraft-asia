# CapitalCraft — World Capitals

A mobile-friendly world capitals study and quiz app. No framework or build step required.

## Files
- `index.html` — dashboard and continent selection
- `study.html` — searchable, filterable country/capital directory
- `quiz.html` — multiple-choice quiz (10 questions or all countries)
- `data.js` — country and capital dataset
- `styles.css` — shared responsive theme
- `common.js` — theme preference and local quiz history

## Run
Open `index.html` in a browser, or upload all files to the same GitHub Pages folder.

## Features
- Dark theme by default, with a light-theme toggle
- Theme preference persists in the current browser
- Responsive mobile-first layout
- Search by country, capital, or continent
- Sort study list by country or capital
- Shuffled quiz questions and answer choices
- 10-question or full-continent quiz
- Immediate answer feedback and progress indicator
- Quiz history and best score stored locally

## Privacy / storage
Quiz history and theme preference are stored in the browser's `localStorage`. They are not sent to the site owner or shared with other visitors. Different devices and browsers have separate local data. Clearing browser site data will reset this information.
